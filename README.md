# 智能客服 Agent 学习项目

这是一个可本地运行的 Web 智能客服最小闭环：客户实时对话、DeepSeek 函数调用、中文本地 RAG、只读订单查询、转人工、坐席工作台与可脱敏回放。

## 启动

1. 在项目根目录复制环境模板：`Copy-Item .env.example .env`。
2. 在 `.env` 中填写 `DEEPSEEK_API_KEY`。密钥只会由 API 服务读取，浏览器不会得到它。
3. 启动服务：`npm run dev`。
4. 打开 `http://localhost:5173/chat`。

其他工作台：

- `http://localhost:5173/agent`：查看并接管待处理工单。
- `http://localhost:5173/admin`：导入 Markdown 知识与查看运行回放。

首次导入知识时会下载并初始化本地中文向量模型，因此需要网络且可能需要一点时间。演示订单仅包含虚构的 `A1001` 与 `A2002`，查询工具只读。

## 建议演示路径

1. 在后台导入 `# 退款说明\n七日内可申请退款。`。
2. 在聊天页提问“怎么退款？”，观察回答和来源标签。
3. 提问“订单 A1001 到哪了？”，观察模型调用 `query_order`。
4. 点击“转人工”，再前往坐席页接管并发送回复。

## 验证

运行 `npm test` 和 `npm run build`。自动化测试使用假的 DeepSeek 与本地向量提供器，不会请求真实 API，也不需要密钥。
